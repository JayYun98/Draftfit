# SpecBundle (external project)

SpecBundle is an upstream SpecForge initiative, not a Draftfit model collection.
See the [upstream documentation](https://docs.sglang.io/SpecForge/community_resources/specbundle.html)
and [model collection](https://huggingface.co/collections/lmsys/specbundle).

Draftfit does not maintain a copy of its dashboard or certify those models.
Use the [Draftfit support matrix](../PUBLIC_SUPPORT.md) and
[validation evidence](../MODEL_VALIDATION.md) for this project's capabilities.
