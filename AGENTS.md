# Repository workflow

- English is the repository's primary language. Write documentation, README files,
  code comments, docstrings, user-facing messages, PR titles and descriptions,
  review comments, and commit messages in English. Preserve intentional
  multilingual test fixtures, datasets, and quoted source material.
- Reply to the user in their preferred language; repository content remains English.
- For feature specifications, algorithm or target additions, behavior changes, or
  PR implementation, read `.skill/dspark-spec-to-pr/SKILL.md`. Prose-only changes
  do not require the full training or E2E workflow.
- Preserve existing work and user changes. Continue the relevant specification or
  experiment record; keep dated results and task status out of this file.
- Follow `docs/ENVIRONMENT.md`. Reuse validation only after checking its revision
  and relevance. Report skipped, failed, and unrun GPU checks explicitly; CPU
  checks do not establish GPU correctness.
